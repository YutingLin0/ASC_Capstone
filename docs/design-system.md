# Campaign design and content reference

## Visual system

- Headings: Aptos Black, uppercase. Body and labels: Archivo SemiBold. Embedded PDF metadata confirms these names; web font files were not supplied.
- Modes: blue walking, orange buses, green rail, purple cycling. Navy text and cream artwork backgrounds; white website canvas.
- Website palette approximations: #4076C5, #F59300, #17B143, #6165BE, #0C1D32, #FFFFFF. The infographic retains its original color-managed SVG colors and stat-box fills.
- Motifs: angular routes, hollow interchange circles, textured transport illustrations, four-color bars, rounded information panels.
- Layout: responsive content columns, persistent section navigation, full-width infographic, readable supporting copy, and PDF downloads at the end.

## Page sequence

Campaign introduction → interactive journey → investment fact sheet → four outreach posters → official NYMTC resources → fictional information session → downloads.

The journey begins and ends with a complete infographic. In between, scroll controls the camera, traveler, route drawing, and mode content. The final mode selection treats each illustration, description, and stat panel consistently. Reduced-motion users see the interactive overview without scroll-driven movement.

## Source grounding

Reviewed materials: the one-page ASC Capstone Research brief; the fact sheet (content on pages 2–3); the journey infographic; and the outreach poster PDF (four messages on pages 2–5).

The research brief centers on first/last-mile access and investment → improvement → connection → journey. Website copy follows those themes without adding new measured outcomes. Long Island and Hudson Valley project examples are labeled as regional examples rather than NYC projects. Expected benefits are distinguished from measured results.

The brief also proposed a social media series, but no separate social media asset was supplied.

Verify each statistic’s primary source, reporting period, geography, project funding/status, and poster QR destination. Supply licensed web fonts if exact website typography is required. Replace the fictional event with confirmed details and a registration service if an actual event is offered.
